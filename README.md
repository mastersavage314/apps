# Parallax 2.0 and ALT 327K 2.0

Two installable web apps for Earth and Gaia.

- **Parallax 2.0** (`/high-noon/`): a live world clock, with a sandbox for any offset, saved clocks, custom zones and a clock dial on each planet.
- **ALT 327K 2.0** (`/thin-air/`): an altitude sandbox showing what the air does at any height, and who lives up there.

The folders keep their first names, High Noon and Thin Air, so existing links and installed copies keep working.

Each app works offline after the first visit. The start page at the root links to both and lists the install steps.

Fonts: Barlow and Big Shoulders Display, under the SIL Open Font License 1.1 (see `fonts/OFL.txt` in each app).
